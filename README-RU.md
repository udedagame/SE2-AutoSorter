# AutoSorter для Space Engineers 2

[English version](README.md)

**Один клик в инвентаре терминала: железо к железу, никель к никелю, компоненты — в контейнер с компонентами.**

AutoSorter добавляет кнопку **«Сортировать»** (три полоски) в шапку каждого списка инвентаря терминала — рядом со штатными кнопками «показать/скрыть пустые» и «только подключённые». Нажатие наводит порядок в контейнерах этого списка. В фоне без вашего нажатия ничего не происходит.

Это **плагин**, который ставится вручную (через параметр запуска игры `-plugins:`), а не мод из Steam Workshop. BuildPlanner не нужен.

## Что делает кнопка

- **Одинаковое к одинаковому.** У каждого вида предметов есть «дом» — контейнер, где его уже больше всего. Мелкие кучки этого вида переносятся туда.
- **Компоненты — в контейнер с компонентами.** Если «дом» смешанный (руда *и* компоненты), а другой контейнер содержит только компоненты и в нём есть место, домом становится он.
- **В следующий — только если полон.** Если дом полон, кучка переносится к *более крупной* кучке того же вида; если места нет нигде, она остаётся на месте.
- **Спокойно.** То, что уже лежит дома, не трогается; в полный контейнер ничего не толкается; повторное нажатие почти ничего не делает.
- **Переносы проверяет сама игра.** Каждый перенос — то же самое, что перетаскивание мышью: игра сама проверяет конвейер, доступ и вместимость. После каждого переноса плагин ждёт, пока окно покажет результат, и только потом делает следующий.
- **Только грузовые контейнеры** того списка, где нажата кнопка. Пустые контейнеры, скрытые фильтром «скрыть пустые», тоже используются. Инвентарь персонажа, очистители, сборщики, торговцы и коннекторы не трогаются.
- **Сортируются только руда, слитки и компоненты.** Инструменты и оружие (игровые *и* из модов), расходники, датапады, квестовые предметы и чертежи остаются на своих местах.
- **Исключить контейнер:** добавьте `[NoSort]` или `[Не сортировать]` в его название.

## Инструменты остаются в рюкзаке

Штатная быстрая выгрузка (**Alt + правая кнопка мыши** по контейнеру) выгружает всё, кроме короткого списка «необходимых» предметов, где нет модовых инструментов. AutoSorter на время выгрузки добавляет в этот список все инструменты и оружие, зарегистрированные в игре (включая моды вроде AreaTools), — и они остаются в рюкзаке.

## Установка

1. Скачайте **`AutoSorter-0.3.0.zip`** в разделе **Assets** релиза (не архивы GitHub «Source code»).
2. Закройте игру. Распакуйте всю папку **AutoSorter** в постоянное место, например `D:\SE2Mods\AutoSorter`. Все DLL должны лежать вместе.
3. В Steam: **Space Engineers 2 → Свойства → Общие → Параметры запуска**, укажите:

   ```text
   "-plugins:D:\SE2Mods\AutoSorter\AutoSorter.dll"
   ```

   Вместе с BuildPlanner — **один** параметр, пути через `;`:

   ```text
   "-plugins:D:\SE2Mods\BuildPlanner\BuildPlanner.dll;D:\SE2Mods\AutoSorter\AutoSorter.dll"
   ```

   Подставьте свои пути. Если `-plugins:` уже есть, допишите путь в него через `;` — второй `-plugins:` не добавляйте.
4. Запустите игру, откройте контейнер, вкладка **«Инвентарь»**: кнопка с тремя полосками — справа вверху каждого списка.

В `AutoSorter.log` рядом с DLL должны появиться строки `AutoSorter 0.3.0 starting` и `Hook installed on InventoryList.InitializeComponent`.

**Обновление с 0.2.x:** закройте игру и замените файлы. Старый `AutoSorter.json` подходит: с ним кнопка включена, а старая автосортировка по таймеру **выключена**.

**Удаление:** уберите путь из `-plugins:`. Плагин не добавляет блоков и не меняет файлы игры; перенесённые предметы остаются там, где лежат в сохранении.

## Настройки

Файл `AutoSorter.json` рядом с DLL (после изменения перезапустите игру). Отсутствующие ключи берут значения по умолчанию.

| Настройка | По умолчанию | Значение |
|---|---|---|
| `Enabled` | `true` | Общий выключатель |
| `ManualButton` | `true` | Кнопка «Сортировать» |
| `AutoSort` | `false` | Старая фоновая сортировка (каждые `IntervalSeconds`). Это сортировщик 0.2.1 **без** исправлений 0.2.2 для стыковки: он может переносить груз между станцией и пристыкованным кораблём. Не рекомендуется |
| `StepDelayMs` | `50` | Пауза между переносами одного нажатия, 16–2000 мс |
| `TransferTimeoutMs` | `5000` | Сколько ждать подтверждения и обновления окна; при превышении нажатие безопасно останавливается |
| `MaxTransfersPerPress` | `500` | Предел переносов за одно нажатие |
| `DryRun` | `false` | Только записать в журнал, что было бы перенесено |
| `IntervalSeconds`, `MaxTransferAttempts`, `MaxItemChecks`, `SoftTimeBudgetMs` | | Только для `AutoSort` |

## Журнал

В `AutoSorter.log` для каждого нажатия записано: какие контейнеры участвуют (пронумерованы сверху вниз), какие пропущены и почему, решение по каждому виду предметов (`sort` / `KEEP IN PLACE`) и каждый перенос (`Move 173 x SteelTube_Item: #1 -> #2`). При сообщении об ошибке приложите журнал и укажите версию игры.

## Ограничения

- Локальные миры (сервер работает внутри процесса игры). Удалённые и выделенные серверы не поддерживаются.
- Блоки с несколькими инвентарями (производственные) не сортируются.
- Кнопка сортирует все контейнеры, показанные в этом списке. Если в списке несколько сеток (например, станция **и** пристыкованный корабль), сначала выберите одну сетку в выпадающем списке.
- Собрано и проверено на сборке игры 4.0.0.3165. Обновление игры может изменить внутренний API: тогда плагин запишет ошибку в журнал, а игра продолжит работать без кнопки.

## Сборка из исходников

Нужны .NET 9 SDK и ваша установленная копия Space Engineers 2.

```powershell
dotnet build AutoSorter.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\SpaceEngineers2\Game2"
dotnet run --project tests/AutoSorter.Tests.csproj -c Release
```

`package.ps1` собирает, прогоняет тесты и создаёт `AutoSorter-0.3.0.zip`; `build.cmd` делает то же по двойному щелчку и ставит плагин в `D:\SE2Mods\AutoSorter`, если такая папка есть.
